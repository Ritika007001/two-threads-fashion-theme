# Changelog

All notable changes to the Two Threads theme. Versions follow [semantic versioning](https://semver.org/): a new first number means merchants should re-check their customizations, a new second number adds features, a new third number only fixes bugs.

## 1.0.0 — 2026-10-25

First public release.

- Home page with hero banner, shop-by-category tiles, featured products, image with text and journal highlights, all with built-in placeholder photos.
- Product page with gallery, star rating, size guide and size finder, shipping notes, reviews, related products and a sticky add-to-cart bar.
- Collection pages with filters and sorting, cart page with suggestions, journal, contact page, content pages, 404 and password page.
- Customer account pages: sign in, create account, forgot password, account overview, order details and address book.
- Six languages built in: English, German, French, Spanish, Italian and Dutch.
- Footer social links block, language and country/currency selectors, and a favicon setting.
- Sample prices and shipping notes use euros to match the European market.
- Four colour schemes (Cream, Sage, Ivory, Charcoal) with Playfair Display and Work Sans fonts bundled under the SIL Open Font License.
